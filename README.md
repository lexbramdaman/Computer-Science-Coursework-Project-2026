# Computer-Science-Coursework-Project-2026
This is my coursework project that I made in secondary school for Computer Science in 6th year. I developed a Python based environmental hazard detector using a microbit, Streamlit, Pandas, Altair and CSV data processing. Live data was processed through serial communication between the microbit and the computer, where sensor data was processed and validated. I created algorithms where based off of the light, temperature and motion of the microbit, the risk of a wildfire occurring would be calculated accordingly. Similarly, landslide risk would be calculated based off of motion values. An interactive Streamlit dashboard was present, with separate “what if” simulation,  allowing users to change temperature, light and motion values and immediately see how the predicted risk changes and live data modes. Data visualisations were formed using Altair, displaying sensor readings and calculated risk levels alongside safe, warning and danger zones for the readings. Sensor readings were stored in CSV format and Pandas was incorporated in order to retrieve, process and analyse the collected data.
